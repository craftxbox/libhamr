# libhamr
*read: hammer*  
Static URL compressor and QR code optimizer -- Library edition.
See [p2r3/ha.mr](https://github.com/p2r3/ha.mr)

## Usage

Install the package via npm:

```bash
npm install libhamr
```

Then, you can import it in your code like so:

```typescript
import { compress, decompress } from "libhamr";
```
